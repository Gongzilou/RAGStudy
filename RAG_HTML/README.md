# 知答 · 产品知识库助手

这是一个独立的静态网页前端，调用项目现有的 FastAPI 问答接口，不需要修改后端代码。

## 接口约定

- 请求：`POST /chat`
- 请求体：`{"question": "你的问题"}`
- 成功响应：`{"answer": "助手回答"}`
- 默认接口地址：`http://127.0.0.1:8000/chat`

## 打开页面

可以用 VS Code 的 Live Server 打开 `index.html`，或在 `RAG_HTML` 目录启动任意静态 HTTP 服务，然后在浏览器中访问页面。确保 FastAPI 服务已启动；项目中的 API 启动入口是 `rag_app.py`。

若后端不在默认地址，可在 `app.js` 中修改 `DEFAULT_API_URL`，再重新加载页面。

## 跨域说明

当前 FastAPI 应用没有配置 CORS。若页面与 API 的协议、主机或端口不同，浏览器会拦截跨域请求；仅修改前端无法绕过此浏览器安全限制。要在不修改后端的前提下使用，需要通过反向代理将页面和 `/chat` 暴露在同一个源下；否则需由项目维护者在后端配置允许前端来源的 CORS。

## 功能

- 自适应桌面端与移动端布局
- 示例问题、Enter 发送和 Shift+Enter 换行
- 请求中状态、网络错误提示与 API 连接状态
- 清空当前页面对话

每次提问都会按后端接口发送单个 `question`；前端不会把聊天历史附加到请求中。

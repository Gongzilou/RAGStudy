# 知答 · 产品知识库助手

这是一个独立的静态网页前端，调用项目现有的 FastAPI 问答接口，不需要修改后端代码。

## 接口约定

- 请求：`POST /chat`
- 请求体：`{"question": "你的问题"}`
- 成功响应：`text/plain` 流式文本，响应体是助手回答的文本内容，不是 JSON
- 默认接口地址：`http://127.0.0.1:8000/chat`

## 打开页面

确保 FastAPI 服务已启动；项目中的 API 启动入口是 `rag_app.py`。FastAPI 同时托管此静态页面，启动服务后访问 `http://127.0.0.1:8000/` 即可使用，页面与 API 同源，不需要额外配置 CORS。

也可以用 VS Code 的 Live Server 打开 `index.html`，或在 `RAG_HTML` 目录启动任意静态 HTTP 服务。此时页面和 API 通常不在同一个源；浏览器可能因跨域策略拦截请求，需使用同源反向代理，或由后端配置允许该前端来源的 CORS。

若后端不在默认地址，可在 `app.js` 中修改 `DEFAULT_API_URL`，再重新加载页面。前端请求会在 180 秒后超时，问题输入上限为 2000 个字符。

## 开屏动画

首次打开页面时会播放一次约 2.15 秒的几何开屏动画：三个环形拼片从不同方向汇合并旋转，背景色从中心扩展，随后细线向上下延伸，最后左右门片连同图案两半一起打开。同一标签页会话内再次刷新不重复播放；系统启用“减少动态效果”时会跳过动画。动画图形使用三块二维环形拼片，不直接复用侧栏六边形与“知”字组合标记，以支持拼合和中线开门效果；颜色沿用页面的浅色背景与绿色系。参数集中在 `styles.css` 的 `:root` CSS 变量中：背景色、铺色、图案颜色、总时长、描边时长、起始旋转角度、图案尺寸、线宽和缓动函数。

## 功能

- 自适应桌面端与移动端布局
- 示例问题、Enter 发送和 Shift+Enter 换行
- 请求中状态、网络错误提示与 API 连接状态
- 清空当前页面对话

每次提问都会按后端接口发送单个 `question`；前端不会把聊天历史附加到请求中。后端返回非成功 HTTP 状态时，页面会显示请求错误；成功响应则按文本流逐段显示回答。

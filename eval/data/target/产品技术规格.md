# 星云 X2 智能手表 · 技术规格

## 屏幕
- 尺寸：1.43 英寸 AMOLED
- 分辨率：466 x 466，亮度 1000 尼特

## 电池
- 容量：410 mAh
- 标准模式续航：14 天
- 重度使用续航：7 天

## 防护
- 防水等级：5 ATM（50 米）
- 表身材质：铝合金

## 传感器
- 光学心率传感器、血氧传感器、加速度计、陀螺仪、气压计
- 定位：GPS / GLONASS / 北斗

## 系统与兼容
- 操作系统：星云 OS 2.0
- 兼容：Android 8.0 及以上、iOS 13 及以上
- 连接：蓝牙 5.0、Wi-Fi 2.4G
